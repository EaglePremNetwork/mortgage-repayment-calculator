## Overview

A mobile-first responsive mortgage repayment calculator built with React, TypeScript, Tailwind CSS, and Vite. Users can enter a mortgage amount, term, interest rate, and mortgage type to calculate their monthly repayments and total amount payable over the selected term.

The application includes client-side form validation, input handling, error states, a clear-all option, and responsive layouts for both mobile and desktop screen sizes. It supports both Repayment and Interest Only mortgage calculations, including calculations for a 0% interest rate.
